# D007: Public source and example license

Status: resolved. Date: 2026-09-30.

Use MIT for this new repository and example code authored for Blob Intake. Public
documentation and example deployment are authorized by D005. Include the license
with published source and preserve third-party attribution/dependency license
requirements. MIT permission does not license provider services or remove their
terms and fees. Public source must exclude credentials, signed URLs, uploads and
private account/runtime state.

The first public offering is a useful BYO integration/example with accurate limits,
not a subscription or guaranteed security service. No recurring paid subscription
or monetary billing is needed for the requested launch milestone.
